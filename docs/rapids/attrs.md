# 属性容量单位

这份表用于给装备、套装和通用词条做统一预算。`1U` 表示一个 universal 属性容量，不等于任意属性的 `1 unit`；表中的数值是容量等价的起始标尺，不代表在所有目标、等级和面板下拥有完全相同的 DPS 或生存收益。

## 统一基准

普通 `base` 类通用词条的常见区间为 `0.25 ~ 1.00 × base`，取中位数后定义：

```text
1U = base × 0.625
```

## 1U 对应属性表

| 属性 | 每 `1U` 的推荐值 | 说明 |
| --- | ---: | --- |
| 命中 | `base × 0.625` | 与闪避相对抗 |
| 闪避 | `base × 0.625` | 与命中相对抗 |
| 会心 | `base × 0.625` | 与柔韧相对抗 |
| 柔韧 | `base × 0.625` | 降低受到暴击的概率 |
| 护甲 | `base × 0.625` | 固定减伤，收益按防御曲线递减 |
| 魔法抗性 | `base × 0.625` | 固定减伤，使用与护甲相同的曲线 |
| 固定护甲穿透 | `base × 0.625` | 百分比穿透之后结算 |
| 固定魔法穿透 | `base × 0.625` | 百分比穿透之后结算 |
| 近战攻击 | `0.481 melee unit` | 近战武器单位，不建议直接按 `1U` 写成 `1 unit` |
| 箭矢攻击 | `0.581 arrow unit` | 箭矢武器单位 |
| 魔法攻击 | `0.962 magic unit` | 魔法武器单位 |
| 最大生命 | `health × 0.30 ~ 0.32` | 低等级按区间下限，高品质或防御型套装再取上限 |
| 生命恢复 | `health × 0.20 ~ 0.25 /s` | 受持续战斗时间影响，作为近似值使用 |
| 单系元素强化 | `element × 0.15` | 每一系独立计算 |
| 单系元素抗性 | `element × 0.25` | 每一系独立计算，防御价值略高于同量强化 |
| 最大法力 | `+10` | 固定值 |
| 法力恢复 | `+0.25 /s` | 固定值 |
| 移动速度 | `+10% ~ 12%` | 已包含机动性的高收益，建议控制上限 |
| 攻击速度 | `+0.10 ~ 0.125 次/s` | 近战与箭矢使用 |
| 施法速度 | `+0.15 ~ 0.18 次/s` | 魔法使用；需注意最低施法速度限制 |
| 箭矢速度 | `+10% ~ 15%` | 同时改善箭矢抵达时间 |
| 暴击伤害 | `+10 ~ 15` 个百分点 | 不是 `10%` 的乘算伤害 |
| 百分比护甲穿透 | `+5% ~ 8%` | 目标防御越高，实际收益越大 |
| 百分比魔法穿透 | `+5% ~ 8%` | 与百分比护甲穿透采用同档预算 |
| 生命偷取 | `+2% ~ 3%` | 受触发间隔、单次恢复上限和实际命中率影响 |

### 全属性的计价

单系元素强化或抗性表中的数值只覆盖一系。`全属性强化`、`全属性抗性`同时覆盖六系，不能按照单系的一份容量处理；至少要按六个独立属性的总预算核算，再根据实际玩法中元素覆盖率做折扣。

## 攻击属性的结论

`sub-attributes.yml` 中普通攻击类通用词条的随机范围是 `0.125 ~ 0.25 weapon unit`，平均约为 `0.1875 weapon unit`。所以：

```text
+0.75 weapon unit ≈ 4 条普通攻击通用词条的平均值
```

如果这里的 `weapon unit` 指近战攻击，则它相当于：

```text
+0.75 melee unit ≈ 1.56U
+0.75 arrow unit ≈ 1.29U
+0.75 magic unit ≈ 0.78U
```

因此，武器已经提供 `1 ~ 2 unit` 时，普通静态装备或套装直接再给 `+0.75 melee unit` 确实偏高。除非该套装几乎不再提供其他输出属性，否则建议把装备攻击奖励控制在 `+0.25 ~ 0.50 weapon unit`；`+0.75` 更适合高品质的最终奖励，且应与会心、穿透、攻速等输出属性互斥或明显降档。

## 使用原则

1. 先把套装奖励换算成 `U`，再比较不同属性组合的总容量。
2. 同一套装的 `2` 件、`4` 件、`5` 件奖励按累计总预算检查，不要只看最后一档的单项数值。
3. 百分比属性、全属性和特殊机制优先按低档估算；实战中若触发率、覆盖率或目标密度较高，再上调。
4. 会心、命中、闪避、穿透等属性受目标面板影响，表中的容量是同等级基准下的起点，不是永远固定的等价 DPS。
